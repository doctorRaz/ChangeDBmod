# ChangeDBmod 0.6

## Изменения

- Проект переведён на SDK-style проекты и переработана структура решения.
- Сборки разделены по средам: AutoCAD 2018+, nanoCAD 21+.
- Централизованы настройки сборки, версии и выходные каталоги.
- Добавлены автоматическая CI-проверка сборки и NUnit-тесты.
- Настроена автоматизация релизов: подготовка архивов, release notes и update manifest.
- Добавлен репозиторный `NuGet.Config` для воспроизводимой загрузки зависимостей.
