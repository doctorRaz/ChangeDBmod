Общедоступные Методы
Имя
Описание
ExportXml
Экспортировать содержимое проекта в xml, никаких коррекций не производится, просто внутренняя модель
GetActiveNode
Получение активного в закладке проекта узла, appType - PPR, Bridge, etc
GetDefaultNode
Получение узла по умолчанию, appType - PPR, Bridge, etc
GetDocument
Получение документа для узла документа в проекте, Load - загрузить если не загружен проект автоматически закроет документы открытые в фоновом режиме при закрытии проекта
GetDocumentNodeID
Получение NodeId для документа, Add - добавляет документр в проект если его не было
GetDocumentPath
Получение пути документа для узла документа в проекте
GetNode
Получение узла по его id
GetObjectNode
Получить объектную ноду по GUID объекта, эта функция нужна что бы имея GUID объетка, не получая объекта найти другие ноды
GetObjectNodes
Получить объектные ноды по GUID объекта, эта функция нужна что бы имея одну именованную ноду можно было не получая объекта получить остальные
GetRootNode
Получение корневого узла для приложения, appType - PPR, Bridge, etc
ImportXml
Импортировать содержимое проекта из xml, никаких коррекций не производится, просто внутренняя модель
RemoveDocument
Метод RemoveDocument, член класса McProject.
Save
Путь к файлу проекта, он же стартовая папка для расчета путей
UpdateAll
Принудительно обновить все документы
UpdateObjects
Принудительно обновить объекты в документе
