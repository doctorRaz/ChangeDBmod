Invalidate
Метод зовётся с целью очистить все данные объекта и привести его в невалидное состояние.
OnDeserialization
Метод OnDeserialization, член класса McCustomBase.

OnEventEx
Вызов событий объекта, param1, param2 содержат значения параметров, зависящих от события.
OnExplode
Событие на разбивку объекта командой EXPLODE.
OnGetExplodedGeometry
Событие на на получение графического образа объекта.
OnGetGripPoints
Функция возвращает грип-точки объекта, старая версия, желательно использовать метод, возвращающий GripPointsInfo.
OnGetOsnapPoints
Функция возвращает точки прилипания к объекту по отношению к указанному режиму и точкам pickPoint и lastPoint
OnGetParamAtPoint
Функция для переопределения штатной реализации Параметр для привязки к объекту по точке
OnGetPointAtParam
Функция для переопределения штатной реализации Точка на объекте по параметру привязки
OnMatchProperties
Копирует свойства с указанного объекта в этот объект
OnMoveGripPoints
Реактор на перемещение грип-точки, indices - Список индексов перемещаемых грип-точки в массиве, полученном из OnGetGripPoints(), offset - смещенение, IsStretchMode - паралельный сдвиг
OnPersistentReactor
Событие на постоянный реактор (постоянный реактор добавляется через DBEntity.AddReactor).

Событие на постоянный реактор (постоянный реактор добавляется через DBEntity.AddReactor).
OnQueryUpdateLevel
Позволяет переопределить очередь обновления объекта
OnTransform
Функция вызываемая у пользовательского объекта при трансформации
OnUpdate
Функция, вызываемая у пользовательского объекта при обновлении объекта, до перерисовки.
PlaceObject
Расширенная функция вставки объекта, во флагах содержатся дополнительные опции
SetAsPrimitive
Данные методы используются в командах trim и extend, обработке геометрических зависимостей, и возврате методов AcDbCurve GetAsPrimitive должен вернуть линию, дугу или полилинию в SetAsPrimitive приходит тот же тип геометрии, который отдан в GetAsPrimitive, и idsOnPrimitive - объекты лежащие на кривой (если есть конечно, например окна на стене и т.п.).
TryModify
Метод, который обязательно надо вызывать перед изменением состояния объекта, вызов этой функции сохраняет Undo взводит статус измененного объекта, ставит объект в очередь на обновление.
