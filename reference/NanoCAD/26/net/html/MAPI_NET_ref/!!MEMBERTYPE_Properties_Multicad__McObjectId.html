Ниже перечислены свойства класса McObjectId.

Class

McObjectId Class

Общедоступные Свойства
Имя
Описание
ClassName
Если идентификатор ссылается на реальный объект, свойство соответствует имени его класса.
DebugString
Отладочная информация по идентификатору
DwordOf3dFeature
Если ID относится к 3D фиче, возвращает ассоциированный с ней уникальное в пределах её host-тела целое число.
GsMarker
Свойство отдаёт соответствующий подобъекту маркер, если таковой возможно получить.
Handle
Соответствующий хэндл объекта в документе IdHostTopDoc.
HostFeatureOrParentId
Если IsFEV = true, свойство равно ID 3D-фичи создавшей эту грань/ребро/вершину.
HostFeaturesIds
Если IsFEV = true, свойство - список ID всех 3D-фич, создавших эту грань/ребро/вершину.
IdHostDoc
Свойство IdHostDoc, член класса McObjectId.
IdHostTopDoc
Свойство IdHostTopDoc, член класса McObjectId.
IsEdge
Свойство определяет, ссылается ли ID на ребро 3D тела
IsFEV
Свойство определяет, ссылается ли ID на грань/ребро/вершину 3D тела
IsFace
Свойство определяет, ссылается ли ID на поверхность 3D тела
IsGuid
Если true, то идентификатор по сути является Guid-ом, к объекту никакого отношения
IsHardRef
Если true, то идентификатор является жесткой ссылкой на объект чертежа, при deep-клонировании объект по ссылке также должен склонироваться
IsInexactFEV
Если ID, относится к FEV, то определяет, нужно ли искать этот элемент Brep в модели неточно - только по создающей фиче.
IsNull
Свойство IsNull, член класса McObjectId.
IsObject
Если true, то это явное указание того, что идентификатор относится к объекту чертежа
IsSubEntity
Если true, то ID относится к подобъекту (вроде поверхности 3D-солида)
IsVertex
Свойство определяет, ссылается ли ID на вершину 3D тела
MdFtrGuidOf3dFeature
Если ID относится к 3D фиче, возвращает уникальный идентификатор операции построения, которая создала Face/Edge/Vertex.
MdFtrIdxOf3dFeature
Если ID относится к 3D фиче, возвращает индекс операции построения, которая создала Face/Edge/Vertex.
Null
Свойство Null, член класса McObjectId.
ParentId
ID объекта-родителя (Если IsSubEntity = true)
RefKey
Если ID относится к Face/Edge/Vertex, то свойство содержит Ref-ключ соответствующего объекта.
RootFeatureID
ID исходной фичи, которая его создала в первичном теле.
ShortString
Первые три символа строки ToString() без скобок (для отладки)
