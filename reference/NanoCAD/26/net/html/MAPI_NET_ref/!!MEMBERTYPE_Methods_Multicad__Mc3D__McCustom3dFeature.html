Общедоступные Методы
Имя
Описание
BuildFeature3dModel
Метод должен строить фактическую 3D модель фичи в переданном на вход теле.
GetClassName
Метод GetClassName, член класса McCustom3dFeature.
GetCriticalDependsOn
Выполняет почти те же функции, что и getDependsOn, но в возвращаемый список объектов помещается то, без чего объект не сможет существовать.
GetDependent
Метод запрашивает у объекта список всех объектов, которые зависят от состояния данного.
GetDependsOn
Метод запрашивает у объекта список всех объектов, от которых зависит состояние данного.
GetECS
Устанавливает матрицу трансформации объекта из ECS в WCS, если return false - не использует; т.е.
GetProfiles
Метод должен вернуть все эскизные профили, от которых зависит состояние данной фичи.
GetTypeID
Метод - helper для реализации property TypeID, зачитывает Guid, связанный с классом и указанный в CustomEntityAttribute
Invalidate
Метод зовётся с целью очистить все данные объекта и привести его в невалидное состояние.
NeedAddVarsToDependsOnList
Метод нужно использовать для проверки необходимости добавлять переменные в список GetDependsOn на производном объекте.
OnEdit
Редактирование объекта
OnErase
Событие на удаление объекта.
OnEvent
Вызов событий объекта, param содержит значение параметра, зависящее от события,
OnEventEx
Вызов событий объекта, param1, param2 содержат значения параметров, зависящих от событий
OnGetProfileID
Реализация метода должна вернуть хранимый в объекте ID эскиза, ранее установленный в OnSetProfileID, либо как-то иначе.
OnGetReactorsToThis
Метод должен добавить в переданный список реакторы к данному объекту
OnQueryStoredGeometryOfFevDependency
Метод должен возвращать сохраненную геометрию для указанного F/E/V, idFEV должен быть из списка getDependsOn.
OnReactor
Событие на реактор от объекта (реактор добавляется через DBEntity.AddReactor).
OnSetProfileID
Метод должен быть реализован в фичах, которые строятся на основе эскизного профиля.
OnTransform
Функция вызываемая у пользовательского объекта при трансформации
OnUpdate
Функция, вызываемая у пользовательского объекта при обновлении объекта, до перерисовки.
SupportMcStreamSerialization
Для включения режима синхронизации через последовательный поток нужно вернуть true
Suppress
Подавляет построение самого объекта и всех от него зависящих в дереве истории построения
Unsuppress
Восстанавливает построение самого объекта и всех от него зависящих в дереве истории построения
_EditEpilog_ForProfileBaseedFeature
Метод нужно звать после фактического редактирования фичи в OnEdit в случае, если на построена на эскизном профиле
_EditProlog_ForProfileBaseedFeature
Метод нужно звать до фактического редактирования фичи в OnEdit в случае, если на построена на эскизном профиле
_EndRead
Метод нужно звать на конец процедуры чтения объекта
_ProcessReactorFromGeomObj
Метод выполняет типовую обработку реактора от геометрического объекта, состояние которого определяет состояние этой фичи.
_RemoveReactorsToThis
Метод-хэлпер.
_SetBaseProfileID_ForProfileBaseedFeature
Вызов обязателен для фич, построенных на базе эскизного профиля.
_SetInternalFeratureTfm
Использовать метод для установки новой абсолютной матрицы трансформации фичи в общей базовой реализации.
_SetReactorsToThis
Метод-хэлпер.
_UpdateEpilog
метод завершает обновление объекта-фичи Все аргументы типа bool*, это адреса дополнительных флагов, чьё взведённое состояние можно интерпретировать, как изменение геометрии this-фичи; (!) список аргументов надо заканчивать значением NULL
_UpdateProlog
Метод нужно звать в начале OnUpdate.
_Update_ProcessPosChanged_ForProfileBaseedFeature
Метод нужно звать в конце OnUpdate, но до _UpdateEpilog, для фич, построенных от эскизного профиля.
mcs_reset
Метод mcs_reset, член класса McCustom3dFeature.
read
Используется для чтения данных класса из последовательного потока с тэговыми данными
write
Используется для записи данных класса в последовательный поток тэговых данных
