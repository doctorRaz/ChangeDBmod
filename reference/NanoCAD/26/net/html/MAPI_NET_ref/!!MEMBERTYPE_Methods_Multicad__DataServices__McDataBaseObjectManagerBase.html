Описание
CreateTemplate
Метод для создания шиблона из мастера объетков, по умолчанию не имплементирован
EditTemplate
Метод вызываемый при редактирования объекта из базы, по умолчанию загружает объект через LoadObject и запускает onEdit, при s_ok - сохарняет объект через SaveObject
LoadObject
Метод helper для загрузки объекта из базы, documents может быть null, т.е используйте этот параметр только из функции EditTemplate, где он явлется входным
Place
Метод вызываемый при вставке объекта из базы, по умолчанию загружает объект через LoadObject и запускает Place
SaveObject
Это обзор перегрузок SaveObject.
